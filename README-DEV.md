# UI — локальная разработка

Актуальное веб-приложение: **`apps/web`** (`@couragegang/web`).

```bash
cd ui
pnpm install
pnpm dev:web
```

Откроется http://localhost:5173 — полноэкранный чат, меню ☰ справа.

Папка **`web-ui/`** устарела: `pnpm dev` внутри неё проксирует в `apps/web`.

Если видите старую вёрстку (сайдбар «Чат / MCP / Подключения» без стилей):

1. Остановите все процессы на порту 5173.
2. Запустите `pnpm dev:web` из `ui/`.
3. Жёсткое обновление страницы: Ctrl+Shift+R.
